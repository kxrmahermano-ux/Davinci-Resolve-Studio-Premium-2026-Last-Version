## 🎨 A Quick Tour of the Four Rooms

**Edit** is where most of your time is spent. The left side holds your media, the right side holds your timeline, and the top right shows a preview. Keyboard shortcuts make trimming fast — J, K, and L control playback, and the blade tool slices clips.

**Color** looks intimidating at first, but start with the color wheels. Drag the small dot in the middle of a wheel to shift the overall tint. Use the curves panel to darken shadows or brighten highlights. The scopes on the right show you the real numbers behind what your eyes see.

**Fusion** uses nodes — small boxes connected by lines. Each box does one job, and the output of one feeds the next. Start with a simple text node, then add a blur node after it to see how the chain works.

**Fairlight** is a full mixing console. The most useful beginner tools are the normalize button on the clip inspector and the noise reduction effect for cleaning up room hum.

## 🛠️ Common Questions

**Do I need a powerful computer?**
A modern laptop can edit 1080p comfortably. 4K and 8K benefit from more memory and a dedicated graphics card.

**Can I edit without internet?**
Yes. Once the software is on your machine, everything runs locally. An internet connection is only needed to download it.

**Will my old project files still open?**
Projects made in recent versions generally open without trouble. Always keep a backup copy of important work before updating.

**Why is playback choppy?**
Reduce the timeline resolution in the project settings, or generate optimized media. Choppy playback is almost always a performance setting, not a broken file.

**Where do exported videos go?**
Wherever you told the Deliver page to save them. Check that path before clicking Render.
